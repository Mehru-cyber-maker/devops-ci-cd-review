# Validation of this prototype

The following checks were executed for this version:

| Check | Outcome |
|:--|:--|
| Python unit and interface tests | 31 passed |
| Synthetic benchmark | 27 cases: 5 valid, 22 faulty |
| Clean browser example | PASS; all 10 rules passed |
| Reused-scan browser example | BLOCK; EG008 failed |
| Stale-scan browser example | BLOCK; EG009 failed |
| High-severity browser example | BLOCK; EG010 failed |
| Browser results filter and JSON download | Passed |
| Duplicate-key JSON upload | Rejected with a readable error |
| Desktop and mobile layout | Checked at 1440px and 390px widths |

Unit tests also exercise timestamp boundaries, conflicting digests, malformed nested types, Trivy digest handling, HTML escaping, CLI exit codes, and loopback HTTP restrictions.

Browser checks used headless Chromium through Playwright. These are development tools, not runtime dependencies. Python tests use only the standard library.

The checked-in synthetic benchmark results are generated by the evaluator, not manually entered. The source dataset and every decision are available in `examples/synthetic-benchmark/`.

This validation does not include a live Trivy scan, cryptographic signature verification, a production CI deployment, or a user study. Such work remains part of the proposed empirical research.
